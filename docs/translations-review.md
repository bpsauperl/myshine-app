# Translations: choices to review

Drafts in `lib/l10n/app_sl.arb`, `app_de.arb` and `app_sr.arb` (`app_sr_Latn.arb` is a copy of `app_sr.arb`). English (`app_en.arb`) is the source. Each line below is a choice a native speaker should confirm.

## All languages
- "by SmileLabs" became "od SmileLabs" / "von SmileLabs" / "od SmileLabs". Should it stay English, as a brand line?
- "myShine pass" on the code card became "myShine ključ" (sl, sr) and "myShine Pass" (de).
- "Plan" stays "plan" everywhere (never "TP").
- A date more than a week away has no preposition in sl and sr ("Alajner 5 4. nov.", "Rok: 4. nov."). Is "dne 4. nov." / "Rok: 4. nov." better?
- Tab names: Today / Plan / Schedule / Messages / Profile became "Danes / Plan / Urnik / Sporočila / Profil", "Heute / Plan / Zeitplan / Nachrichten / Profil", "Danas / Plan / Raspored / Poruke / Profil". Do they fit in the tab bar?
- The fit and discomfort chips are short adjectives ("Zelo tesen", "Sehr eng", "Veoma tesan"). Do they read well on their own?

## Slovenian (sl, "ti" form)
- Check-in is "prijava menjave" (button "Prijavi menjavo", done "Menjava prijavljena").
- Clinic is "ordinacija"; dentist is "zobozdravnik" (masculine generic, e.g. "Tvoj zobozdravnik" on Profile).
- Gendered past tense is avoided: "Alajner 5 je nameščen" (not "Vstavil/a sem…"), "Alajner 5 že nosim", "Že nosiš alajner 5?".
- "Days left" uses "preostali dan / preostala dneva / preostali dnevi / preostalih dni" after the number.
- "Treatment" is "zdravljenje" (Today, Plan); "terapija" would also work.
- "Your smile, revealed." became "Tvoj nasmeh, razkrit."
- The preview is "predogled"; the "after/before" tags are "Potem / Prej".
- The note hint is "Karkoli naj vedo (neobvezno)".
- "Prekineš povezavo z myShine?" for "Disconnect myShine?"

## German (de, "du" form)
- Check-in is "Wechsel bestätigen" (eyebrow "Dein Wechsel", done "Wechsel bestätigt am 24. Okt.").
- The dentist's row on Profile says "Zahnarzt/Zahnärztin". "Zahnarztpraxis" is used where a sentence needs one.
- "Due on Thursday." became "Fällig am Donnerstag."; late: "Seit 2 Tagen fällig."
- "Your smile, revealed." became "Dein Lächeln, enthüllt."
- "Shine clear aligners" became "Transparente Shine Aligner".
- "Aligner 5 ist drin. Danke!" for "Aligner 5 it is. Thank you!" may be too casual.
- "Handy" is used for "phone" ("Dieses Handy"). Should it be "Smartphone"?

## Serbian (sr, Latin, "ti" form, ekavian)
- Check-in is "potvrda zamene" (button "Potvrdi zamenu", done "Zamena potvrđena").
- Clinic is "ordinacija"; dentist is "stomatolog".
- The preview is "prikaz", not "pregled", because "pregled" also means a dental check-up.
- Gendered past tense is avoided: "Alajner 5 je postavljen", "Već nosim alajner 5", "Nosiš li već alajner 5?".
- "Days left" uses "preostali dan / preostala dana / preostalih dana" after the number.
- "Treatment" is "terapija".
- "Your smile, revealed." became "Tvoj osmeh, otkriven."
- Email is "E-pošta" (or "Imejl"?).
- On a phone set to Serbian (Cyrillic), the app forces Latin script, Material's own words included.
